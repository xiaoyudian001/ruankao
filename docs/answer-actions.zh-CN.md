# 编辑问题、重新生成与导出

## 使用入口

真实问答页 `/textbook` 中，已完成或失败的问题下方有“编辑问题”。点击后在输入框修改题目，发送会追加一条回答并关联原问题，不覆盖旧问题或旧答案。如果已经写了其他草稿，会先确认替换；编辑关联会随草稿保存在当前浏览器。

已完成回答提供“重新生成答案”。同一问题会重新检索和生成，保留原答案。它不会保证结果与原答案不同，也不会覆盖当前未发送草稿。原题型、检索模式和截图沿用原记录；原问题尚未完成、服务离线、已有任务处理或模式不可用时不能提交。

关联回答显示“编辑后提问／重新生成”及可跳回原问题的入口。新的回答各自保留教材引用、运行状态和收藏入口。失败重试保留这次操作的关联；提交结果不明时仍按原请求编号确认，不改成另一种操作。

## 上下文

服务器检查原任务属于当前所有者和当前会话。新尝试复用原问题提交时保存的最多三轮 `history_json`，不会把原答案及原问题之后的讨论当作重答上下文。正常新增提问仍采用现有多轮历史规则。

编辑关联期间模式、题型及原截图受到保护；需要作为普通新问题提交时，点击“取消关联，保留文字作为新问题”。原记录和后续对话始终保留，这不是复杂的对话分支树。

## 会话导出

右上方“导出 Markdown”下载服务器已保存的当前会话，包含：

- 所有原问题、编辑后问题及重生成记录，以及彼此关联。
- 已完成答案、失败说明或仍在等待的状态。
- 每条回答自己的片段编号、教材页码标签、PDF 页码和章节。
- 原题截图访问链接；原图不嵌入文件，访问仍需原网站登录权限。

导出不调用大模型，不包含未发送草稿、任务 lease、会话 history_json、服务配置或完整检索原文。每个会话最多 200 条，与聊天现有限制一致。已删除或不属于当前账号的会话不能导出。
