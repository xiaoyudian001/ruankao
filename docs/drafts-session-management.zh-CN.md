# 草稿与历史会话

真实问答页 `/textbook` 已支持以下能力，公开 `/demo` 仍是预录示例。

## 草稿

- 问题文字、检索模式、问答／真题类型，以及已完成识别的截图编号自动保存到当前浏览器 localStorage。
- 按已登录账号和会话分别保存，新建会话也有独立草稿。切换会话、刷新或重新打开浏览器后可恢复，30 天未更新过期。
- 下方提示保存或恢复状态；“清空草稿”清除当前草稿及设置。浏览器拒绝保存时提示保留页面或复制文字。
- 成功发送后只清理与这次问题一致的草稿。其他会话的草稿、后续修改和另一标签页更新的内容不会被随意清空。
- 提交响应中断时，仍按原 requestId 确认任务；不会自动重复生成。未确认提交的恢复记录保持按标签页隔离。
- 原图文件不写入 localStorage。恢复已识别截图时读取其私有服务记录，展示原图、保留核对状态，不用识别文字覆盖修改后的题目。截图失效或网络失败时可重试恢复或移除关联。
- 未完成识别的本地图片无法跨刷新保留，页面提示先完成识别。

草稿仅在当前浏览器保存，不跨设备同步；清除网站数据会清除草稿。

## 历史管理

- 左侧搜索匹配标题、提问文字和回答正文。服务器检查全部未删除聊天，并按最近活动排序；每页 50 条，可“加载更多会话”。搜索百分号等符号时按字面匹配。
- 每条会话提供重命名和删除入口。名称为 1～80 字，不允许换行；重命名不修改原问题或引用。
- 删除前明确确认。删除采用逻辑删除，聊天列表、搜索、会话恢复及继续提交都不再打开该会话。为保留已收藏答案、复习卡片及其原页引用，服务器仍保留来源任务；不是永久擦除全部存储数据。
- 排队／运行中的会话不能删除；后台以原子条件再次检查，避免并发提交时删除正在执行的任务。
- 管理接口只允许网站所有者、同源修改，不管理案例、论文或截图识别内部记录。
