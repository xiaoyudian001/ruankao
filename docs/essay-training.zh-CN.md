# 论文写作训练

入口为 `/essays`，首页、教材问答和案例练习顶部均有「论文训练」。仅网站所有者可访问。

## 使用步骤

1. 填写训练名称、论文主题、题目要求和真实项目事实。项目事实建议包含背景、本人职责、业务约束、架构方案、选择理由、实施问题及实际效果；不了解的内容如实说明。可使用匿名名称。
2. 点击「保存并生成论文提纲」。AI按题目要求组织段落，关联已有项目事实和教材技术依据，并列出仍需补充的问题。不会为缺失的项目经历和效果自动填写数字。
3. 选择摘要、项目背景与职责、架构方案与技术选择、实施过程与问题解决、效果与总结之一，先写自己的稿件，再点击「保存并点评这一段」。
4. 对照切题度、项目具体性、本人职责、技术取舍、问题解决和表达结构修改。点击蓝色片段引用，可回看该次实际检索的教材文本与原PDF页。
5. 修改后再次提交；每次任务保留当时的项目材料、论文要求、稿件和材料版本，历史点评不会随编辑被覆盖。

项目材料和段落草稿可在电脑离线时保存到D1；AI训练依赖本机Langflow、Ollama与连接器。浏览器草稿按材料版本保留在本机，训练记录与保存的稿件仅对所有者可见。

## 实现机制

- `lib/essays/model.ts`：材料、五个段落、草稿恢复与训练参数契约。
- `app/api/textbook/essays/route.ts`：所有者及同源验证、创建、版本保存、幂等任务与不可变快照。服务器从已保存材料构造模型输入，不采信浏览器伪造的事实或引用。
- `textbook-bridge/essays.py`：仅论文主题与题目要求进入教材检索，项目材料不加入教材向量库。项目事实和选定稿件作为当前模型资料。
- `textbook-bridge/single_pass_components.py`：沿用既有MiniMax正文模型。论文任务独立提示词和资料，输出沿用可信引用校验，必要时在总时限内恢复一次格式。
- `drizzle/0010_tricky_plazm.sql`：追加论文与训练记录表、任务私有载荷和论文可用状态，不改写旧迁移。
- 内部`essay`任务复用已有队列，与普通聊天历史隔离；来源仍以该次保存的片段快照为准。

每次保存检查材料版本，过期编辑不会覆盖新版本。一次论文训练只允许一个任务排队或运行；同一请求标识不会重复调用模型。项目事实、要求和稿件是资料，不能改变模型系统规则。

## 验证与边界

32项Node契约测试、11项隔离SQL测试通过；连接器76项测试中71项通过，5项因公开源码没有私有教材图示目录而跳过。论文路由验证权限、同源、幂等、版本冲突、资料快照和引用；静态渲染验证历史原稿与蓝色引用。类型检查与应用构建通过。

合成项目材料的实际模型测试：提纲生成约33秒，分段点评约51秒，两次均返回有效教材出处。合成材料不是用户真实项目，没有写入用户的论文训练记录。浏览器完整点击操作尚未逐项验证。

AI建议不是官方评分，不能保证判断准确或考试结果。教材依据说明技术理论，不能证明某个项目事实成立；资料不足时应由用户补充真实情况。当前提供提纲和分段训练，不包含自动生成完整可提交论文、官方评分细则或项目真实性验证。
