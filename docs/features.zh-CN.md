# 已实现功能清单

功能基线：V21功能及本次多题型/案例练习更新，2026-10-12。以实际代码和已发布流程为准；早期设计文档中的未勾选步骤属于当时记录，不是当前线上状态。

## 学习工作台

- `/`：40天六阶段路线、学习打卡、学习时长、题数、学习状态和今日复习任务。
- 资料分类保存、下载与删除，单个文件最大25MB；上传资料不会自动加入教材向量库。
- `/review`：答案收藏、卡片编辑、主动回忆和40天计划。日期按`Asia/Shanghai`处理。
- 自评决定排期：新卡今天到期；没记住或部分记住安排次日；连续记住按1、3、7、14天推进。
- AI点评采用收藏时的教材证据，说明正确、遗漏、需要纠正及练习建议；不自动修改用户自评或排期。

## 教材问答

| 能力 | 实际处理 | 相关代码 |
| --- | --- | --- |
| 当前问答 | 稳定检索链及父级上下文扩展 | `textbook-bridge/bridge.py`、`sysarch-fullbook/parent_context.py` |
| 完整检索 | 按需拆分、语义与关键词召回、融合、重排和子问题覆盖 | `sysarch-fullbook/complete_retrieval.py`、`hybrid_retrieval.py`、`local_rerank_runtime.py` |
| 多轮追问 | 最近3轮已完成问答；独立问题不必改写，指代不明确时澄清 | `lib/textbook/conversation.ts`、`sysarch-fullbook/conversation_rewrite.py` |
| 来源引用 | 真实片段、印刷页与PDF物理页、跨页范围、原页侧栏 | `lib/textbook/sources.ts`、`app/textbook/source-panel.tsx` |
| 输出清理 | 隐藏`<think>`区域，校验模型返回格式及实际采用来源 | `textbook-bridge/exam.py`、`figures.py` |
| 一次答案生成 | 先准备证据，再选择正文或图文模型生成；异常回退有明确边界 | `textbook-bridge/single_pass.py` |

正文检索向量是BGE-M3文本嵌入。BM25按词项匹配，RRF按排名融合，本地CrossEncoder重新判断问题与候选的相关性。相似度、RRF分数和重排logit不是同一数值，也不直接等于答案正确概率。

## 教材图文

- 指定图号时精确查找；描述性问题检索图题、章节和同页正文。
- 对候选执行语义/BM25/RRF与本地重排，每轮最多两张教材原页。
- 图像由本机原PDF渲染并验证来源哈希，不公开上传教材全集。
- 表格、公式有独立原页内容索引；按需要读取相关页，核对行列、单位与变量。
- 只有模型实际采用的原页进入最终图文引用和展示。
- 普通问答图文失败可明确标注后回退正文；用户截图题失败时不静默丢弃原题图像。

## 真题解析与截图

### 文字题

支持粘贴题干、选项和可选的标准答案，独立检索教材。返回答案、思路、逐项解释、知识点和引用。模型判断不标为官方答案，也不凭空补全缺失选项。

同次可生成一道四选一辅助练习。有效练习需要唯一正确项、不同的四个选项及有效教材来源。服务端在提交前只返回题干和选项；提交后揭晓解析，同一选项重试幂等，第一次提交后不能更换答案。已保存练习无需重新调用模型判分。

### 截图题

接受PNG/JPEG/WebP上传或粘贴，最多两张同一道题截图。浏览器转换与缩放后保存PNG，单张上限2MB。识别结果最多2000字，另给注意事项；用户核对、修改和确认后发送。

原题图表随文字进入图文模型，不能当成教材引用。截图私有保存，读取检查所有者；桥接取图检查有效任务租约、PNG信息和SHA-256。历史回答可回看原题，错误重试保留原图。

## 来源数据处理

本机脚本已实现分批PDF解析与缓存、RapidOCR、中文词内空格和断行清理、跨页切片、保守水印处理、稳定分片ID、断点续传与页码映射。默认检索正文；目录和封面的保存不等于默认参与问答。

`SysArchTutorRAGv3`是当前部署实例的知识库名称，不是源码自带的数据库。原PDF、正文、向量、图示索引、模型和流程配置需在本机另外准备。
