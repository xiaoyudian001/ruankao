# 真题解析

聊天页选择“真题解析”，粘贴题干和全部选项（2000字以内）。当前问答/完整检索仍可选择。所有者账号和同源限制沿用原接口；客户端不能提供教材证据、练习答案或判分。

`task_type=exam → 独立问题 → v19证据准备 → 一次MiniMax解析与练习 → 分段标签解析为JSON → D1保存 → 练习提交`。

原题可包含单选或多选，生成的类似题固定四选一，属于AI辅助练习，不是官方真题。结果没有官方答案保证；可随题附标准答案核对。第一版不支持截图上传。原题包含“以下/这个选项”等措辞时不按普通追问缺对象处理，保留完整题干及选项做独立检索，检索诊断中将换行压为单行。

题干需要表格、公式、图示时沿用最多两张原页；只有干扰选项包含“服务器”等词不触发视觉检索。模型仅使用实际送入的材料，引用citation字段[片段N]。练习正确项、互异选项、字段长度和引用来源在Python与站点两端检查。原图未采用时其引用不能成为练习依据。练习字段的格式或来源失效时丢弃练习，保留同次原题解析。

新增D1迁移0007只追加字段，旧任务默认qa、旧心跳默认exam_ready=0。升级连接器声明examReady后才接受新解析任务。原Q&A任务与回忆点评继续用原有互斥队列和过期lease规则。

GET /api/textbook/chat在未提交练习时只返回question/options，不发送correct/explanation/ranks。POST /api/textbook/exam提交jobId和choice；只保存第一次有效选择，同选项重试幂等，换选项返回409；提交后GET可恢复选择、参考答案和解析。练习无需再次调用模型或等待电脑连接，解析里的引用沿用同一来源快照。

真实模型验证与发布记录保存在本机F:/daily/output/sysarch-exam，不公开模型凭据、原教材文件、完整验证材料或连接密钥。浏览器QA沿用此前安全限制，通过实际API、SQLite、React SSR、应用类型检查和生产构建验证。
