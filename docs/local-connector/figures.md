# 教材原图问答

原有文字检索完成后，使用本轮完整检索对象寻找原图。明确的“图12-2”等图号优先精确匹配，不调用嵌入。描述性图示问题将图题、章节及最多1800字符的同页正文分别用于BGE-M3语义召回与BM25关键词召回；两路各取20条，通过RRF(k=60)合并去重取前8条，用已安装的mmarco-mMiniLMv2-L12-H384-v1本地CrossEncoder重排，再选最多2张。实际命中的正文页码仅用于相关性同分时排序，不能使低相关图通过筛选。

独立向量索引位于本机 `output/sysarch-figure-rag/figure-vectors.npz`，清单位于同目录 `figure-vectors.json`。`build_figure_vectors.py`使用本机Ollama bge-m3:latest构建，不修改正文Chroma知识库。向量文件与教材SHA、catalog SHA、检索文档SHA、模型digest、条数/维度一起校验；同版本缓存可复用。索引或本地模型故障会回退图题/正文页匹配，没有相关图示时沿用文字答案。图示语义索引是“图题和正文”的文本嵌入，不是原图像素向量。

图题在BM25中增加权重；截取融合候选池时保留两路各自第一候选，避免一种召回信号被全部挤出。重排logit不是概率；低于-3的候选不进入视觉模型，高语义前3或图题匹配强的候选可进入最终图像相关性检查。所有规则仍受最多2图限制，MiniMax不采用的图不会展示。连接器启动时后台预热本地模型，预热状态写入本机status.json的figure_hybrid_ready；不阻塞普通文字问答。

本地目录 `output/sysarch-figure-rag/catalog.json` 索引了 218 张具有图题的正文原图。图像仍在本机，不随网站构建公开发布。`build_figure_catalog.py` 检查 PDF 哈希，保存原图哈希、裁剪范围、页尺寸、同页正文和已核对的教材/PDF 双页码。

每次最多两张图，使用现有 MiniMax-M3 配置调用独立的“教材图表问答 · 原图与正文”流程，温度 0.1。模型必须返回实际采用的图 ID；不相关的图不进入最终回答。满十条文字引用时，为图片预留最多两条引用，重新生成的答案只使用该次实际送入模型的来源。图片步骤受本轮剩余时限约束，失败保留文字答案并明确提示原图未解析。

网页显示采用的教材原图，并通过已有受保护的原页接口加载页面后裁剪展示。点击可查看完整原页与同页正文。图元数据需属于实际引用页，不能由浏览器指定任意教材页。本功能优先支持有图题的架构图、流程图；无图题插图和复杂公式不保证自动匹配，正文表格继续使用现有文本解析。

真实验证：图12-2“三层 C/S 与 B/S 架构”，教材412页/PDF427页。模型识别了两条三层链条及其双向箭头；普通职责问题和MTBF问题不触发原图解析。
