# 一次答案生成（v19）

## 执行路径

`问题处理 → 当前/完整检索伴随流程 → 原页选择与准备 → 一次答案生成 → 引用校验 → 网页`。

原检索配置保持一致。当前模式使用原知识节点和父级扩展；完整模式仍包含问题拆分、语义/BM25/RRF、本地重排及子问题覆盖。追问按原受限历史补全，新检索问题与原问题分别保留，历史不作为教材证据。

`setup_single_pass.py`创建两个仅准备证据的伴随流程及一个生成入口；本机`single-pass-flows.json`保存实际ID，不打包公开。检索流程移除答案模型、最终清理与聊天输出，保留原Parser和提示模板。EvidenceSnapshot返回原有序来源、元数据及渲染后的模板。新的生成入口实例化两个原模型句柄，仅调用选中的一个：正文温度0.2，图文温度0.1，均为MiniMax-M3。

## 回退与来源

先准备最多两张真实原页，没有相关原页时只生成正文答案。图文模型未采用原页时保留同次正文结论，移除未采用原页卡片，不重新生成。原页准备失败只做一次正文生成；图文执行/输出校验失败才允许一次正文回退，复用相同检索快照，不重新检索。图文回退用原完整文本模板及来源，不沿用已裁减的视觉编号。

单一数值计算优先使用排名第一的公式原页和已标注同章的正文，减少不同章节变量定义混入本题；章节未知时不猜章节。显式比较、跨章、多个公式或分别计算的问题保持最多两页的完整范围。正文回退仍使用原检索快照。

JSON继续通过base64传递；模型正文标签由Python验证并序列化。原图固定路径、SHA、两图与十来源上限和双页码规则延续v18。普通文本引用使用原引用清理；视觉引用只接受实际保留的来源编号。原Langflow问答流程和图文流程保留，网页新请求由连接器选择新入口。

## 本机耗时记录

`F:/daily/textbook-bridge/stage-timings.ndjson`保存成功任务的任务ID、时间与毫秒耗时：

| 字段 | 范围 |
|---|---|
| questionMs | 问题/受限历史处理及必要的追问重写 |
| textRetrievalMs | 原检索流程总耗时，含完整模式规划、向量化、BM25、融合、重排和父级扩展 |
| visualRetrievalMs | 原页目录查找及视觉文本的语义/BM25/RRF选择，不包含下两项 |
| visualRerankMs | 视觉候选本地CrossEncoder重排 |
| imagePrepareMs | 原页渲染、SHA检查及图片base64准备 |
| generationMs | 答案生成HTTP调用及返回处理；回退时累计两次 |
| answerCalls | 最终答案生成次数；正常1、澄清0、图文失败回退2 |
| totalMs | 本机整个问答耗时 |

零值表示阶段跳过。问题重写与完整模式规划是独立模型调用，不计入answerCalls。日志不保存问题、历史、正文或凭据。网页原有总耗时继续展示，不增加一组诊断界面。

不以样例耗时承诺所有问题加速；长答案、完整检索规划、冷启动仍可能增加等待。浏览器视觉检查遵循此前安全限制，本轮用真实流程和来源接口验证。

## 实测（2026-10-11）

50项连接器测试通过，10项网页来源/历史/访问契约测试通过。实际正常路径的答案生成入口调用数均为1：

| 样例 | 总耗时 | 生成耗时 | 原页 |
|---|---:|---:|---|
| 可用性数值计算 | 32.329秒 | 22.457秒 | PDF628，教材613；结果99.5% |
| 表2-2跨页权限比较 | 38.470秒 | 29.550秒 | PDF55、56，教材40、41 |
| 架构设计师职责 | 22.566秒 | 14.722秒 | 正文来源，无图片 |
| 完整检索追问能力要求 | 68.505秒 | 44.153秒 | 正文来源，无图片；对象补全成功 |

公式与表格来源已通过网页来源契约校验。表格初次输出触发正文回退，后续精简指令复测通过；回退仍真实计为2次，不隐瞒重试成本。v18公式样例耗时34.45～47.87秒；本轮32.329秒仅是样例，不能当作普遍加速比例。完整追问的68.505秒包括6.249秒对象补全和18.103秒检索，说明规划和长答案仍会影响等待。
