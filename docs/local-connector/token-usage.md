# 网页 Token 用量

聊天页每条已完成回答展示输入、输出 Token 和原有耗时，展开可查看合计、模型、已统计调用数和统计范围。旧记录以及模型没有返回 usage 的记录显示“Token 用量未提供”，不按字数估算。

统计范围为答案生成：包含格式重试和图文回退中可以获取的真实用量，不包含问题重写、检索规划、证据判断或嵌入。流式响应使用最后一份完整累计报告，每个请求只计一次。失败调用缺失统计时提示“部分调用用量”，展示的合计仅表示已知用量。输出是模型服务的 Token 口径，可能包含推理，不能和网页可见字数比较。

模型组件保留 usage_metadata（或 response_metadata.token_usage），连接器携带可选 tokenUsage，完成任务时与原租约一同写入 token_usage_json。网页历史读取重新验证字段；取消任务不写入最终用量。追加 D1 迁移 0014，仅新增可空字段。

本机更新先备份，再运行 activate_token_usage.py：只修改现有生成组件的用量收集代码，保留全部提示词、节点和连线。verify_token_usage.py 用自写材料分别验证普通和流式调用，不保存测试答案，只记录用量和长度。实际图文的逻辑通过独立响应及回退回归测试验证。

新用量仅从更新后的模型调用获取，历史记录不能追溯补算。
