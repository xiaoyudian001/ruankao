# 论文写作训练实施计划

**目标**：基于用户已经确认的「项目经历→论文提纲→分段写作→切题与案例点评」，增加论文训练入口。

**设计**：沿用所有者访问控制、D1、后台任务队列、本机检索及MiniMax。项目材料不加入教材库；仅论文主题和要求用于教材检索，项目事实和本次稿件作为作答资料。训练历史保存不可变快照，编辑项目材料采用版本检查。

## 实施与验收

- [ ] `tests/essays.test.mjs`、`textbook-bridge/test_essays.py`：先验证输入范围、事实传递、独立检索主题、无图文额外输入和有限格式恢复。
- [ ] `lib/essays/model.ts`：项目名称、论文主题、题目要求、项目事实、五个段落草稿的契约；项目事实4000字、主题1200字、要求2000字、每段8000字。
- [ ] `db/schema.ts`：追加论文与训练记录表；教材任务增加私有payload列、连接状态增加essay_ready。使用Drizzle生成新迁移，不改变旧迁移。
- [ ] `app/api/textbook/essays/route.ts`：创建、版本保存、读取、提纲和段落点评；权限、同源、幂等、并发版本、材料快照和队列上限。
- [ ] `textbook-bridge/essays.py`、`bridge.py`、`single_pass_components.py`：从服务器payload取得项目事实；检索主题而非项目材料；生成提纲/分段点评并校验本轮教材引用。事实不足提示补充，不代造项目、指标或官方评分。
- [ ] `app/essays/`：保存项目材料、生成提纲、五段写作、修改后再评、历史版本和蓝色引用；草稿本地恢复，历史云端保存。首页及教材/案例入口互通。
- [ ] 真实路由与隔离SQLite验证所有者、幂等、原稿与材料快照、旧版本冲突、排队与失败恢复、内部任务不出现在普通聊天。
- [ ] 静态渲染、类型检查、构建；本机合成项目材料模型验证提纲和段落点评；发布现有Sites项目并更新中文说明。

**限制**：AI辅助训练，不能保证评分；没有官方细则不输出官方分数。基于明确保存的项目事实评论，未知内容列为待补充。浏览器完整交互测试若不可用，明确报告验证边界。
