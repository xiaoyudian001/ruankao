# 教材问答AI兜底 Implementation Plan

**Goal:** 普通教材问答在证据不足时补检索一次，仍不足则提供清楚标记且无教材引用的MiniMax通用知识。

**Architecture:** 复用现有生成组件，新增仅内部使用的证据判断任务；返回sufficient/partial/none及有范围限制的扩展查询。普通文字QA才使用此判断，案例、论文、截图、明确只按原文及已有原图输入保留原规则。阶段共用原220秒预算；判断失败沿用教材路径，不把异常当成无证据。partial按两段独立校验后合成Markdown，none生成时不传无关教材片段。

**Tech Stack:** Python连接器、Langflow、MiniMax，现有网页Markdown显示和来源协议。

## 顺序

- [x] `test_qa_fallback.py`：验证最多两次检索、无来源的通用补充、部分来源与补充隔离、案例/原图不进入兜底、异常不判无证据。
- [x] `qa_fallback.py`：结构化判断协议、扩展问题范围校验、AI补充引用拒绝、固定来源声明及生成提示。
- [x] `bridge.py`新增证据判断调用；`single_pass_components.py`嵌入判断和两种QA生成分支；`single_pass.py`串联判断、一次扩展检索及最终来源处理。
- [x] 运行连接器检查，更新本机组件与代码，用RTO/RPO与正常教材问题复测。保存私有诊断，不写入用户会话。
- [x] 更新中文说明和README，普通推送GitHub。网页直接复用现有Markdown展示，无新API或数据库迁移。

## 约束

不把检索未召回称作全文教材没有；AI补充不联网、不提供教材出处；不伪造页码，不自动将AI知识写入教材库。恢复调用和证据判断都有限次数及时间。完整教材或原图内容不对外公开，公开源码保留原有许可状态。
