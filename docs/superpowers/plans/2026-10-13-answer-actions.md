# 编辑问题、重新生成与会话导出

**目标：** 保留原记录，支持修改后重新提问、重新生成答案和下载 Markdown 会话。

**设计：** 新任务关联原 source_job_id，并记录 original/edit/regenerate 类型。服务器校验原任务所有者、同会话、终态和删除状态，沿用原检索模式、题型、截图以及原提交时的 history_json，不把原答案或后续对话塞入重答上下文。新任务仍遵守队列、请求幂等和会话 200 条上限。编辑输入与草稿保存结合；重生成不替换已有草稿。导出只读服务器会话，保留每条状态、来源页码、动作关系和截图访问链接，不触发模型。

**技术栈：** React、TypeScript、现有 D1、Drizzle 追加迁移、浏览器下载。

## 边界

编辑不会覆盖原问题，重新生成不会保证答案一定不同。保留所有版本，无复杂分支树和差异编辑器。不改变模型、知识库或检索管线。导出来源链接需原网站登录权限，原图不嵌入 Markdown。本阶段不做流式输出。
