# 真题解析

用户已批准“粘贴题目与选项 → 答案及逐项解析 → 教材出处 → 一道先答后看的类似题”。在既有聊天页加入教材问答/真题解析切换，复用当前/完整检索与MiniMax一次生成入口。首版输入文字，沿用2000字上限；不识别用户截图、不引入题库和官方答案服务。

原题解析用Markdown显示答案、思路、逐项分析和出处，标注是模型结合教材生成的解析，未提供标准答案时不能冒充官方答案。同一次调用生成一道四选一的辅助练习，明确不是历年真题。练习采用结构化question/options/correct/explanation/ranks；服务端检查唯一选项、正确答案与现有来源编号。原题可含多选，练习固定单选。教材不足时允许practice为null并说明不足，不凭空编练习。

新增job task_type（qa/exam）、exam_json、practice_choice与桥接exam_ready字段，兼容旧记录常量默认值。原题作为本轮独立检索问题，不用上一道题补全指代；常规问答历史行为保持。模型一次完成解析和练习；图文失败最多一次正文回退，复用同一证据快照。传输JSON仍走base64；模型用独立文本标签输出练习字段，由Python组装JSON，避免正文引号转义错误。字段顺序可变化，每个字段必须恰好一个；可选练习不合格时保留原题解析，不追加模型调用。只发送本题文字及已授权的教材证据，图片上限两张。普通选择题以题干判断是否需要原图，干扰选项中的图像关键词不单独触发读图。

GET仅返回练习题干和选项，提交前不向浏览器发送correct/explanation/ranks；POST练习选项在所有者/同源检查后原子地保存第一次选择，重试相同选择幂等，之后可读正确答案与解析。客户端无正确答案判分；刷新与切换会话保留提交结果。旧连接器未声明exam_ready时禁止新建解析任务。

验证覆盖隐藏答案、越权/同源、幂等、来源编号、保存与重读、无证据、生成标签及转义、一次生成；执行一个真实教材原题到练习解析的闭环，再构建发布并重启连接器。本轮不重试先前被安全策略拒绝的浏览器QA，以真实API、SQLite路由、SSR与构建验证。
