# 答案增量显示与停止生成

用户已批准上一轮提出的三项范围：正文逐步显示、停止生成、中断保留正文。沿用 MiniMax 及既有检索与输出校验。

## 传递和显示

Langflow 最终生成组件使用现有模型句柄 astream，只从 final_answer 标签抽取正文。think、未闭合标签、结构字段和评分答案不回传。正文暂存于当前 Windows 用户临时目录，目录名由可信任务 UUID 与 lease 构成；生成组件与连接器共享该任务邮箱。连接器最多每秒发送一次有序正文快照，网站现有三秒轮询读取快照，不伪装成逐字符动画。最终答案仍经过原有来源校验，成功后替换临时正文，只有此时开放引用、收藏及练习。

## 停止语义

所有者同源接口可取消当前未删除会话中的 qa/exam 任务。排队任务立即 cancelled；运行任务置 cancel_requested 并保留占用槽位，直到连接器确认或240秒租约超时。连接器轮询控制状态并写本地停止信号；生成组件在等待模型流时也定期检查并取消异步模型读取。检索尚未返回时无法立即中断 Langflow 的检索请求，但停止后不再启动答案生成。关闭客户端流不能保证供应商不再计费。

停止与完成使用同一原子更新边界；停止优先于随后送达的完成。不同 lease、过期任务、终态及旧序号快照拒绝更新。取消正文标明未完成、不可引用，不进入会话历史或收藏；可以编辑或重新生成。失败与超时保留已收到正文。导出带状态而不把残缺正文当完整答案。

## 兼容

仅对聊天 qa/exam 开启增量邮箱；案例、论文、点评、截图识别沿用原行为。新字段有默认值，旧连接器仍可一次性回传最终结果。不显示未经校验的来源。没有有效正文标签时等待最终校验结果。

## 验收

真实 SQLite 路由覆盖 owner/origin、排队取消、运行确认、停止完成竞争、旧序号、租约、删除及隐藏任务保护。Python 验证分裂标签/think、混合答案标识、重试替换、等待流取消和邮箱清理。现有路由、生成格式恢复、类型及生产构建回归通过。上线同时更新本地组件和连接器；真实自写问题验证提前看到正文及停止。
