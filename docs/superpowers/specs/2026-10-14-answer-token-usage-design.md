# 网页答案 Token 用量

## 当前状态

网页答案标题旁仅显示 elapsed_ms。当前生成组件在取得模型响应后只保留 content，未把 usage_metadata 保存到答案结果；流式消费同样需要保留最终用量。因此需要贯通模型响应、连接器、云端任务存储和网页展示。

## 展示方案

在每条已完成回答的耗时旁显示“输入 N · 输出 N Token”。展开详情显示输入、输出、合计、模型及统计范围。采用模型返回的真实整数值，不按文字长度估算。旧记录以及未返回用量的响应显示“Token 用量未提供”，不能显示为零。

统计范围为本次答案生成的模型调用，包括可获取用量的格式重试和图文回退。问题重写、检索规划、证据判断及嵌入不包含在该统计中，详情明确标注“答案生成用量”。有调用缺失用量时标记“部分调用用量”，不把已知合计表示成完整成本。

输入包含模型实际接收的指令、教材片段、受限历史及问题。输出按服务返回的统计口径保存；不能等同于网页可见正文的字数。只有服务明确返回推理用量细分时才展示该细分。

## 数据链路

生成组件读取非流式响应和流式累计响应的实际用量；单轮累计不得重复相加最终流式总计。重试及回退逐次累计已知用量。连接器传递可选用量对象，后台严格验证并与现有任务租约一同保存。新增可空存储字段，历史会话查询返回该字段；标题附近采用原页面排版，不增加独立统计面板。

## 验收

- 已完成普通问答和图文问答可展示实际输入、输出用量。
- 流式答案不重复累计用量；格式重试和回退统计范围有明确说明。
- 服务未提供用量、历史记录和澄清请求不伪造零值。
- 无效用量数据无法写入任务；取消的结果不能覆盖完成状态。
- 页面刷新及切换会话后统计保留。
- 修改不会改变教材检索、提示词、模型温度和答案内容。

## 范围

本次只增加教材问答和真题解析聊天窗口的答案生成 Token 展示。整次 RAG 所有步骤的总用量、费用换算、全站统计不包含在本次实现中。
